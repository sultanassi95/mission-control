# Mission Control - first flight

> This file ships with the product and stays exactly as shipped in your
> clone: never edit it. Before liftoff it starts your liftoff. After it, the
> import on its last line loads your operating instructions from
> `_command/CLAUDE.operating.md`, which LIFTOFF Stage 4 writes and which is
> gitignored with the rest of `_command/`, so a pull that updates this file
> never meets a local edit.

## Instruction to the agent reading this

**If the operating instructions from `_command/CLAUDE.operating.md` were
loaded after this file:** this portfolio has lifted off. Follow them, and
ignore the two cases below.

**If `_command/` does NOT exist in this directory:** this portfolio has
not lifted off yet. Greet the founder with one short paragraph: what is
about to happen (a guided session, 30 to 45 minutes, that stands up their
portfolio operating system - their profile, their projects, their rules),
and the honest expectation (today transfers the framework and their soul;
the lived-in continuity that makes this system impressive is earned over
weeks of real use). Then open `LIFTOFF.md` and follow it stage by stage,
starting at Stage 0 - regardless of what the founder's first message
said. Their "hi" is the ignition.

**If `_command/` DOES exist but no operating instructions were loaded:**
do not start work from this bootstrap. Tell the founder which case it is:

- `_command/CLAUDE.operating.md` is missing in a new instance: liftoff did
  not finish. Resume LIFTOFF; its Stage 0 continues a partial liftoff at
  the first incomplete stage, and Stage 4 writes the file.
- It is missing in an instance lifted off before 2026-10-17: the operating
  text lived in this file, and a pull replaced it (`git stash list` may
  still hold it). `CHANGELOG.md` (2026-10-17) has the steps that move it
  into `_command/`.
- It exists: the import was not loaded. A session opened in a folder
  below this one loads imports from outside its own folder only once they
  are approved, so open the session here or approve them.
